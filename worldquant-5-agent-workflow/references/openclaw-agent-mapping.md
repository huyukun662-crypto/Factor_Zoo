# OpenClaw Agent Mapping

Use this file when running the workflow in an OpenClaw environment that already exposes these agent IDs:

- `knowledge`
- `planner`
- `generator`
- `backtest`
- `evaluator`

## Mapping

### `knowledge`
Use as Research Librarian.

Task focus:
- knowledge retrieval
- operator search
- dataset search
- optimization tips
- example collection

### `planner`
Use as Hypothesis Architect.

Task focus:
- choose one dominant mechanism
- define causal chain
- define success criteria
- define failure conditions
- create session metadata

### `generator`
Use as Alpha Builder.

Task focus:
- produce one coherent batch of exactly 8 expressions
- explain each expression economically
- note turnover and fragility expectations

### `backtest`
Use as Backtest Operator.

Task focus:
- validation
- submission
- monitoring
- results collection
- failure reporting

### `evaluator`
Use as Evaluator & Recorder.

Task focus:
- ranking
- robustness interpretation
- next-step decision
- round logging
- final summary

## Important operating note

The workflow is strongest when the coordinator stays outside these five roles and only manages sequencing, validation, and state updates.

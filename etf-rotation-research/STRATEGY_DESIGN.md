## 1. 标的池设计

### 1.1 探索方法

通过 `akshare.fund_etf_spot_em()` 获取所有上市 ETF 列表（含名称、代码、AUM、日均成交额）。然后用 `fund_etf_hist_em(symbol=code, period='daily', start_date='20130101', adjust='qfq')` 拉取每只候选 ETF 的全历史 (前复权)。

### 1.2 筛选规则

| 维度 | 阈值 | 理由 |
|---|---|---|
| **上市起始** | 不卡死；记录 `available_from`，该日之前 NaN，**不参与当日选股** | 避免幸存者偏差和虚假回填，但又能利用后期上市 ETF 的 alpha |
| **流动性** | 60 日中位成交额 ≥ ¥50M（权益类）；≥ ¥10M（债/货币/商品） | 与现有 V7_gold 接近；保证可执行性 |
| **同标的去重** | 跟踪相同指数仅保留历史更长者，AUM 决胜 | 防止信号冗余、控制相关性 |
| **跨境 (QDII)** | T+1 二级市场结算与境内 ETF 一致，日频回测无需特殊处理 | 仅打标 `is_qdii` 用于风控复盘 |

## 2. 策略设计 — RSRS + 加阶矩双动量

### 2.1 信号 A — RSRS (阻力支撑相对强度)

**理论依据**：光大证券 2017 研报《基于阻力支撑相对强度（RSRS）的市场择时》。在每只 ETF 上滚动回归 `high_t = α + β · low_t + ε`，斜率 `β` 反映多空力量对比：

- `β > 1`：高点抬升速度 > 低点抬升速度 → 阻力上移、趋势走强 → 看多
- `β < 1`：低点下移速度更快 → 支撑被打穿 → 看空

**实现的三个层级**（`signals.py` 提供选项，参数网格择优）：

1. `rsrs_raw` = β（原始斜率）
2. `rsrs_z` = z-score(β, 长窗 M) （标准分 RSRS）
3. `rsrs_skew` = `rsrs_z × R²` （**右偏标准分**，生产首选；R² 抑制低质量回归）

**两种用途**：
- **个 ETF**：进入横截面综合得分
- **大盘 (510300)**：风险开关。`rsrs_skew_csi300` 跌破 `θ_off` 时，整体仓位切换至防守 (债+黄金+货币)

### 2.2 信号 B — 加阶矩双动量

**理论依据**：
- 双动量：Antonacci, *Dual Momentum Investing* (2014) — 绝对动量（与无风险/债 ETF 比较）+ 相对动量（横截面排序）
- 加阶矩：Daniel & Moskowitz, *Momentum Crashes* (JFE 2016) — 动量崩盘往往伴随高偏度反转，引入 skew/kurt 修正

**计算（窗口 L，默认 120 日）**：

```
log_ret_d  = log(close / close.shift(1))
mom_L      = log(close / close.shift(L))
vol_L      = log_ret_d.rolling(L).std()
sharpe_L   = mom_L / (vol_L * sqrt(L))
skew_L     = log_ret_d.rolling(L).skew()
kurt_L     = log_ret_d.rolling(L).kurt()    # excess kurtosis

mom_score  = z(sharpe_L) + λ_s · z(skew_L) - λ_k · z(kurt_L)
```

**绝对动量过滤**：仅当 `mom_L_i > mom_L_{511010}` 时该 ETF 进入候选池。否则当日剔除。

### 2.3 综合得分 + 仓位规则

**综合得分**（横截面 z 后加权）：

```
score_i = w_rsrs · z(rsrs_skew_i) + w_mom · z(mom_score_i)
```

默认 `(w_rsrs, w_mom) = (0.4, 0.6)`，二者之和 = 1.

**调仓规则**：
- 取 `score` 最大的 top-K ETF（默认 K=5），等权
- 仅在候选池（绝对动量过滤 + `available_from ≤ t`）内排序
- 风控总闸（`rsrs_skew_csi300`）：
  - `< θ_off`（默认 −0.7）→ 权益 0%，全仓防守
  - `[θ_off, θ_on)`（默认 [−0.7, +0.7]）→ 权益 50%，防守 50%
  - `≥ θ_on`（默认 +0.7）→ 权益 100%
- 防守桶选择：`{511010, 511260, 511880, 518880}` 中 `rsrs_skew` 最高者
- **换手节流**：目标权重与现持仓 L1 距离 ≤ 5% 时不执行（参数 `rebal_threshold`）

### 2.4 经济直觉小结

| 模块 | 假设 | 主要风险 |
|---|---|---|
| RSRS | 阻力上移、支撑稳固 ⇒ 趋势 | 突变行情下滞后 |
| 双动量 | 涨者恒涨 + 弱者出局 | 反转月失效 |
| 加阶矩 | 高偏度 = 后续大反转预兆 | 偏度估计噪声大 |
| 风险闸 | 大盘破位 = 系统性风险来临 | 闸门误关 = 错失反弹 |

四者**失败模式互不相同**，组合后在 IS 期内有望兼顾胜率与回撤控制。

## 3. 参数空间（IS 阶段迭代用）

| 参数 | 取值 | 备注 |
|---|---|---|
| `rsrs_N` | 14, 18, 24, 30 | RSRS 回归窗口 |
| `rsrs_M` | 250, 600 | 标准分长窗（< 600 时回退 expanding，min_obs=252） |
| `mom_L` | 60, 120, 180, 252 | 动量/偏度/峰度窗口 |
| `lambda_s` | 0.0, 0.3, 0.5 | 偏度权重 |
| `lambda_k` | 0.0, 0.2 | 峰度权重 |
| `w_rsrs` | 0.3, 0.4, 0.5 | 综合权重（`w_mom = 1 - w_rsrs`） |
| `top_k` | 3, 5, 8 | 选股数 |
| `(θ_off, θ_on)` | (−1.0, +0.5), (−0.7, +0.7), (−0.5, +1.0) | 风控带 |
| `rebal_threshold` | 0.0, 0.05, 0.10 | 换手节流 |

完全笛卡尔 ≈ 5184 组，超时间预算。**采样策略**：拉丁超立方 (LHS) 抽 600 组，topN 复算 + 手工聚类细化。

**预定路线图**（执行中可能微调）：

| 轮次 | 主题 | 假设 |
|---|---|---|
| R1 | 基线：默认 RSRS + 双动量 + 加阶矩，等权 top-5 | 验证整体 pipeline 跑通且 IS Sharpe 显著为正 |

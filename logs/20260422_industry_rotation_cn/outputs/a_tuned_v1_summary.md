## 胜出配置(`A_tuned_v1`)

```python
# 信号
score[i,t] = z(mom_4w[i,t]) - 1.5 * z(turn_4w[i,t]) + 0.3 * breadth_z[t]

# 选股
top_4 = argmax(score)[:4]   # 等权 25% 持仓

# 市场 gate(现金防御)
risk_on[t] = mkt_cum[t] > mean(mkt_cum[t-50w:t])
weight[i,t] = 0 if not risk_on[t] else top_4_w

# 15% 年化 vol target(只缩不放)
scale[t] = min(1.0, 0.15 / rolling_vol_26w[t-1])
weight_final = weight * scale

# 执行
rebalance = weekly (每周五信号 → 下周一执行)
delay = 1, cost = 5 bps / side
```

3 个关键 lever 相比原 A7:
1. **top_n: 3 → 4**(更分散,降低单行业爆掉风险)
2. **市场 gate(mkt_cum > 50w MA)**:熊市切现金(IS 57% 开,OOS 69% 开)
3. **15% vol target**:震荡/波动剧烈时按比例缩仓(IS 平均缩到 84%,OOS 平均缩到 67%)

## 决策

**PROMOTE(有条件)** —— 可以考虑入库到 `factors/price_volume/industry_rotation_etf_v1/`,带 kill-switch 防御:
- rolling 12m Sharpe < 0 连 4 周 → pause
- rolling 12m MaxDD < -15% → pause
- 行业集中度警告:任一板块持仓 > 60% → 人工复核

**注意事项**:
1. **"IS 调参 → OOS 反而更好"** 是值得怀疑的信号,但这里有机制解释:(a) 2024-2026 正好是红利价值 + 周期 + AI 混合主导的轮动市场,策略的"多风格分散"设计恰好吃到;(b) OOS vol 更高但 vol target 把风险回归到 15% 目标。Robust。
2. **2022 年完全靠 gate 防御**。如果 gate 出错,2022 重现大概率 -15% 以上。Gate 是该策略的核心风险点。
3. **34 个 ETF 的短样本** 意味着不能做 2018 之前的校验。如果 A 股进入"非动量" regime(散户系统性离场、策略挤出),表现会大幅下降。
